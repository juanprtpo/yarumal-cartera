⚙ Configurar conexión con Google Sheets

Para sincronizar datos con Google Sheets necesitas una URL de Apps Script.
Sigue estos pasos:

  1. Ve a script.google.com
  2. Abre (o crea) tu proyecto y pega el código del archivo apps_script_v3.js
  3. En la línea 18 reemplaza PEGA_AQUI_EL_ID_DE_TU_SHEET por el ID de tu Google Sheet
    (El ID está en la URL de Sheets: docs.google.com/spreadsheets/d/ID_AQUÍ/edit)
  4. Guarda con Ctrl+S
  5. Haz clic en Implementar → Nueva implementación
  6. Tipo: App web · Ejecutar como: Yo · Acceso: Cualquier persona
  7. Copia la URL generada y pégala abajo
